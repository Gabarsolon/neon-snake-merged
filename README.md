# Neon Snake

A neon snake game in a single HTML file. No build step, no dependencies.

**Play it:** https://gabarsolon.github.io/neon-snake-merged/

It also includes every feature from two other snake builds, [snake-game](https://github.com/Gabarsolon/snake-game) and [Cyber Viper 2099](https://github.com/Gabarsolon/cyber-viper-2099).

## Controls

| Action | Keyboard | Touch |
| --- | --- | --- |
| Steer | Arrow keys or WASD | Swipe or D-pad |
| Start | Space or Enter | Tap |
| Overdrive boost (hold) | Space or Shift | BOOST button |
| Pause | P or Esc | Pause button |
| Sound on/off | M | Speaker button |

## Features

- **Overdrive:** hold to double your speed and your score while the tank lasts. Each orb refills it a little; a Nova star fills it up.
- **Food:** every fifth orb is golden and worth five times as much. Nova stars appear now and then, pay the most, and vanish if you're slow.
- **Combos:** eat quickly to build a multiplier. Every fifth link gets a banner: ON FIRE!, UNSTOPPABLE!, GODLIKE!, LEGENDARY!
- **Music:** synthesised live with the Web Audio API. It gets busier and faster as your combo climbs. Sound effects and music can be switched off separately.
- **Options** (on the title, pause and game-over screens): 7 colour themes, solid or portal walls, Chill / Normal / Insane pace, and a CRT filter.
- **Game feel:** bloom, hitstop, shockwaves, particles, screen shake, slow-motion death, glitch effects and confetti for a new best.
- **Records:** your best score, a local top 3, and stats for each run (length, orbs, max combo, time).

Settings and scores are saved in the browser.

## Run locally

Open `index.html` in any modern browser.
